## 📖 Introduction

This repository curates papers on **Test-Time Adaptation (TTA)** algorithms for the **CLIP** model. The papers in this repository adhere to the strict standard of **Online Test-time Adaptation (OTTA)**: only unlabeled test data is used, which arrives in sequential batches, and the model is adjusted incrementally with each batch to produce predictions.
